01

AI Vision — Multi-Camera Waste Monitoring

Autonomous monitoring of waste container sites. A custom fine-tuned YOLOv8 watches IP-camera streams for overflowing bins and scattered litter, raises real-time alerts with snapshots, and forecasts overflow probability for the next 24 hours. Six Docker services run the full loop — from frame capture to the operator dashboard.

How it works

  1. Capture — scheduled snapshots per camera via media server, HLS fallback
  2. Detect — YOLOv8 inference, priority: trash_around › bin_full › bin_empty
  3. Alert — events with confidence + snapshot stored and pushed live
  4. Forecast — gradient boosting retrained weekly, 24h curves per camera
  • YOLOv8 fine-tune
  • mAP50 0.71
  • 11.7k images
  • Precision 0.73
  • Recall 0.75
  • Docker ×6
  • Redis
  • PostgreSQL

AI ANALYTICS

Multi-camera video analytics with people tracking, face recognition, activity reports, handgun detection and floor-plan monitoring. The workspace connects live observations with person records, time reports, zones and movement history.

Features

  1. Live analytics — camera views, people, identities and object overlays
  2. People — person cards, face samples and sighting history
  3. Activity — presence, posture, work / phone / idle estimates and reports
  4. Floor plans — rooms, camera placement, live positions, zones and route replay
  5. Handgun detection — detections within the live camera view
  6. Management — camera status, branch assignment and analysis settings
