01

AI Vision — Multi-Camera Waste Monitoring

Autonomous monitoring of waste container sites. A custom fine-tuned YOLOv8 watches IP-camera streams for overflowing bins and scattered litter, raises real-time alerts with snapshots, and forecasts overflow probability for the next 24 hours. Six Docker services run the full loop — from frame capture to the operator dashboard.

How it works

  1. Capture — scheduled snapshots per camera via media server, HLS fallback
  2. Detect — YOLOv8 inference, priority: trash_around › bin_full › bin_empty
  3. Alert — events with confidence + snapshot stored and pushed live
  4. Forecast — gradient boosting retrained weekly, 24h curves per camera
  • YOLOv8 fine-tune
  • mAP50 0.71
  • 11.7k images
  • Precision 0.73
  • Recall 0.75
  • Docker ×6
  • Redis
  • PostgreSQL

02

Detect — People & Activity Analytics

On-premise multi-camera analytics for Hikvision streams: face recognition, pose and object tracking, work / phone / idle timelines, custom handgun detection, and live floor-plan routes. Shared TensorRT inference serves a four-camera workstation pipeline, while the browser workspace brings identity, activity and location together.

How it works

  1. Capture — isolated SDK workers and shared-memory frame transport
  2. Recognize — SCRFD + ArcFace, track ownership and clothing continuity
  3. Understand — pose / hand-object activity estimates and interval-based reports
  4. Locate — floor-plan calibration, zones, live positions and day replay
  • YOLO11 pose
  • YOLO26
  • ArcFace
  • TensorRT FP16 / INT8
  • Handgun mAP50 0.845
  • FastAPI
  • SQLite WAL

Live: real camera capture from the running application. Map: synthetic demonstration data. The mAP figure is validation performance of the handgun model.
