01

AI Vision — Multi-Camera Waste Monitoring

Autonomous monitoring of waste container sites. A custom fine-tuned YOLOv8 watches IP-camera streams for overflowing bins and scattered litter, raises real-time alerts with snapshots, and forecasts overflow probability for the next 24 hours. Six Docker services run the full loop — from frame capture to the operator dashboard.

How it works

  1. Capture — scheduled snapshots per camera via media server, HLS fallback
  2. Detect — YOLOv8 inference, priority: trash_around › bin_full › bin_empty
  3. Alert — events with confidence + snapshot stored and pushed live
  4. Forecast — gradient boosting retrained weekly, 24h curves per camera
  • YOLOv8 fine-tune
  • mAP50 0.71
  • 11.7k images
  • Precision 0.73
  • Recall 0.75
  • Docker ×6
  • Redis
  • PostgreSQL

AI ANALYTOX — Multi-Camera Intelligence

Live video analytics, face recognition, activity reporting and floor-plan monitoring in one operator workspace. I optimized GPU sharing, analysis scheduling, frame handling and operational history to keep processing resources focused on useful work.

Engineering focus

  1. Share compute — multiple cameras reuse loaded AI models
  2. Control workload — task budgets and analytics selection per camera
  3. Reduce overhead — efficient frame handling, memory limits and compact history
  4. Keep operating — camera isolation, monitoring and controlled recovery
